# cafe-landing

가상의 동네 카페 "모닝브루"의 간단한 랜딩 페이지입니다. 빌드 과정 없이 HTML과 CSS만으로 만들었습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (첫 화면, 대표 메뉴, 소개, 오시는 길) |
| `style.css` | 스타일 (반응형 레이아웃 포함) |

## 실행 방법

`index.html`을 브라우저에서 열면 됩니다.

## 참고

카페 이름, 메뉴, 가격, 주소, 전화번호는 모두 예시 내용입니다. 실제 정보로 바꿔서 사용하세요.
